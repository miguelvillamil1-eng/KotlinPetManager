## 📝 Descripción de la Aplicación
**KotlinPet Manager** es una aplicación móvil para Android diseñada para la gestión de pacientes en una clínica veterinaria. Implementa una arquitectura **MVVM (Model-View-ViewModel)** y está desarrollada con **Jetpack Compose** y **Material 3**.

### Funcionalidades:
- Registro de pacientes (Nombre, Especie/Raza, Edad, Contacto de emergencia y nivel de urgencia).
- Manejo reactivo de estado con `StateFlow` y `mutableStateOf`.
- Renderizado dinámico de la lista mediante `LazyColumn` y tarjetas elevadas (`ElevatedCard`).
- Validación visual inmediata para pacientes marcados con prioridad de urgencia.

---

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Arquitectura:** MVVM
- **Componentes clave:** `Scaffold`, `LazyColumn`, `OutlinedTextField`, `ElevatedCard`, `ViewModel`.
